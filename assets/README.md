# Assets

Diagrams and screenshots referenced from the docs.

Before adding a screenshot, check it does not reveal: a public IP, a Wi-Fi SSID
or password, a token on screen, or account identifiers. Crop or redact first.

Suggested shots: NAS storage pool, Docker/app dashboard, a service UI, the
physical rack or shelf. Name files descriptively, e.g. `nas-storage-pool.png`.
